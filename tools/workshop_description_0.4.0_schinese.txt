[h1]黑夜长留 | Night Must Stay[/h1]
[b]当前版本：0.4.0｜支持《杀戮尖塔 2》正式版及 Public Beta 分支[/b]

来自《艾尔登法环：黑夜君临》的渡夜者们，如今踏入了尖塔！

本模组致力于以贴近《杀戮尖塔 2》原版的设计风格与数值平衡，还原渡夜者们各具特色的战斗方式，并将其融入卡牌构筑玩法之中。

目前已实装五名可玩角色：守护者、铁之眼、复仇者、女爵与追踪者。每名角色均拥有独立的卡牌、遗物与专属战斗机制。

[b]0.4.0 新角色：追踪者[/b]
使用钩爪进入追击，以猛烈攻击打破敌人的架势。追踪者拥有 90 张卡牌、9 件专属遗物与 3 种专属药水，并围绕追击、破势、绝境、活力、冻伤与失衡构建多种流派。

渡夜者们，让黑夜长留于尖塔之中。
