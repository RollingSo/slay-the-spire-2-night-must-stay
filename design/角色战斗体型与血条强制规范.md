# 角色战斗体型与血条强制规范

本规范适用于守护者、铁之眼与复仇者的战斗模型、落地位置、角色边界、血条宽度及战斗锚点调整。

## 1. 尺寸基准

- 唯一基准是原游戏故障机器人战斗场景 `D:\STS2\scenes\creature_visuals\defect.tscn` 的实际渲染可见边界。
- 故障机器人 `process` 动画在 `0.64` 秒的 Spine 附件边界高度为 `2466.646`，场景缩放为 `0.125`，最终可见高度为约 `308.331 px`。
- 不得把故障机器人的 `Bounds` 高度 `260` 当作人物可见高度；`Bounds` 是交互和血条布局范围，不是美术尺寸。

## 2. PNG 角色的测量方式

- 使用 Godot `Image.get_used_rect()` 读取导入后贴图的非透明像素边界。
- 最终可见高度按所有嵌套缩放相乘计算：

  `最终可见高度 = 非透明像素高度 × Sprite 缩放 × 父节点缩放 × Combat Visuals 缩放`

- 外层缩放按目标高度反推：

  `Combat Visuals 缩放 = 308.331 /（非透明像素高度 × 所有内层缩放）`

- 当前三名角色的校准结果：

  - 守护者：非透明高度 `1353`，Sprite 缩放 `0.34`，外层缩放 `0.6703`。
  - 铁之眼：非透明高度 `1210`，Sprite 缩放 `0.36`；按 2026-10-07 用户要求适度放大 `5%`，外层缩放由 `0.7078` 调至 `0.74319`，最终可见高度 `323.733564 px`。
  - 复仇者：按 2026-10-05 用户批准的新形象缩至此前的 `0.7` 倍；待机非透明高度 `1328`，Sprite 缩放 `0.21`，PoseRoot 缩放 `1.2`，外层缩放 `0.6447`，最终可见高度 `215.7527232 px`。个别攻击姿态根据自身非透明高度补偿 Sprite 缩放及脚底位置。

- 守护者最终可见高度与故障机器人的误差必须低于 `0.1%`；铁之眼遵守 2026-10-07 用户批准的放大例外；复仇者遵守用户批准的娇小体型例外，按此前实际可见高度的 `0.7` 倍校准，不再强制与故障机器人等高。商店和篝火也分别按各自此前实际可见高度缩至 `0.7` 倍。

## 3. 落地与锚点

- 缩放后必须用外层 `Visuals.position` 校正非透明像素下边缘，使人物落地点与故障机器人一致，而不是通过扩大透明画布伪造位置。
- `CenterPos`、`IntentPos`、`OrbPos` 与 `TalkPos` 必须跟随同一缩放和位移同步换算。
- 禁止只修改人物缩放而不校正意图、对话、球体特效或中心锚点。

## 4. 通用 Bounds 与血条

- 三名角色的战斗 `Bounds` 统一使用故障机器人的通用范围：

  - `offset_left = -125`
  - `offset_top = -260`
  - `offset_right = 125`
  - `offset_bottom = 0`

- 通用血条宽度由 `Bounds` 的 `250 px` 宽度提供；不得通过缩放人物来修复血条，也不得按人物贴图宽度改变血条长度。

## 5. 何时需要重绘

- 只有在非透明主体边界无法通过等比缩放与位移获得正确落地、轮廓严重被透明留白污染，或统一高度后主体构图明显失真时才重绘。
- 重绘必须保留已确认的角色造型、朝向、装备和色彩身份；不得为了尺寸统一自由改造角色设计。

## 6. 女爵与铁之眼的相对体型（2026-10-07）

- 按用户要求，铁之眼在战斗、商店、篝火各放大此前的 `1.05` 倍，女爵在每个场景的最终非透明可见高度均为铁之眼的 `0.95` 倍。
- 女爵战斗外层缩放为 `0.711914088`，可见高度约 `307.546886 px`；共用外层缩放覆盖待机、攻击、受击、施法、格挡及死亡动画。
- 商店：铁之眼 Sprite 缩放 `0.45402`，女爵 `0.438867083`。篝火：铁之眼 `0.508095`，女爵 `0.438845886`。
- 战斗脚底对齐地面，中心、意图、球体与对话锚点跟随缩放和位移换算；商店与篝火同步调整 Sprite 位置及动画位置轨道，保留原落地位置。
