# 塞巴斯蒂安 Sebastian 美术强制规范

## 2. 一级轮廓与比例

**低伏拱起的大胸腔 + 前伸长颈与裸露头骨 + 极长骨臂和骨手 + 下端残留脊柱，无完整双腿。**

- 主体为巨型半身骷髅灵体，胸腔横向展开、背部拱起，头颈向身前探出。不得默认画成直立人类骷髅站姿。
- 胸腔是身体主要体积，头骨与胸腔关系以参考为准；不沿用“巨大头颅压过全部胸腔”的泛化比例。
- 颈部由清晰连续的多节颈椎连接胸腔和头骨，明显长于普通人形；不得把头直接贴在锁骨上或画成漂浮头颅。
- 两臂异常修长，长骨、肘关节、前臂、腕部和指骨连续；长度不能主要靠放大手掌代替。保留肩胛、肩部骨片和臂骨连接。
- 下部可见脊柱向地面延伸，主体在下端消散；禁止完整骨盆—双腿—双脚的站立骷髅。不能用一大团蓝火遮住全部下端结构。

## 3. 头骨、胸腔与手

- 裸露头骨保留颅顶、深眼眶、鼻腔、颧部、牙列和下颌的形状；头向前低垂或随攻击抬起。无帽子、兜帽、头发或人类皮肤。
- 眼眶以暗部为主，可有克制灵光。不得强制两眼发射光束，或以夸张双眼光点替代头骨形状。
- 肋骨分列形成弧形笼状胸腔，胸腔内部和肋间保留透空；不能画成实体胸甲、封闭白桶或布袍。
- 手部为骨掌和分节指骨，可伸展、屈曲或撑地；以掌骨、指骨连接表达骨手，不套肉掌、手套或金属爪套。不能把前景透视放大的手永久固化为过大的手掌。

## 4. 胸前饰物与无服装要求

- 图5明确可见胸前垂挂细链和多个圆形饰片，必须保留这一识别层次；具体数量及排列按画面清晰度概括。
- 链饰为直接悬挂于骨架前的细线与圆片，不是衬衣纽扣、领结、马甲、管家服或胸甲。旧“全部主体只许骨骼”的表述不能用于删除截图中的饰物。
- 不穿任何布料服装：禁止礼帽、燕尾服、马甲、领结、领巾、袖口、手套和长袍。链饰允许，布料不允许。
- 不持剑、锤、法杖或其他家人装备；攻击主体来自自身骨臂、骨手与头口的灵体效果。

## 5. 动作参考

- 低伏/前探：胸腔前倾、头颈向前，长臂伸向地面或目标；保留胸腔与地面之间的空间，避免误画成四足兽。
- 抬臂：骨臂自肩部向上举起，肘关节折转，前臂沿大弧线伸向前下方；不能从胸腔任意位置额外生出手臂。
- 前伸骨手：肩—上臂—肘—前臂—腕—掌保持连续；手部可以按透视放大，另一臂可以遮挡但不能消失成不存在。
- 能量动作：图4支持以头骨口前为能量焦点，放射方向朝前。作为视觉设计时使用口部/头骨前方灵魂波或放射形，取消旧规范强制“从眼眶释放光束”的要求。
- 这些截图提供姿态与效果方向，不能推定完整招式顺序、命中次数或精确发射机制。项目动画应围绕已见姿态设计，不声称未验证的逐帧复刻。

## 6. 灵体材质与项目画风

- 骨架、链条、圆饰统一使用冷白半透明灵体、蓝灰暗部及冷青至白色亮边。无需推测实体骨色或金属本色；不新增金色链饰、黄骨或实体银色金属反光。
- 肋间、眼眶和关节负空间保留暗部与透明空隙，亮边不能把所有骨骼粘成白色团块。
- 将截图细密闪烁和表面噪点简化为少量透光色块、轮廓亮边与灵雾；不复制写实骨纹、电影模糊、密集白点或彩虹色散。
- 用大块平涂、硬边赛璐璐、粗黑形状与有限色板概括体积；骨节和牙列按缩略图需要简化，不以高频细节承担身份识别。
- 深海蓝黑可作背景区分色，不把主体染成不透明深蓝骨架。能量特效不能遮住长颈、头骨或胸腔。

## 7. 资产用途与技术要求

- 战斗贴图沿用家人规范的 `512×512` 真透明 PNG，四角 alpha=0，默认面向右侧敌人，画面无环境、地面阴影、UI或边框。
- 相对奥斯提 `1.2×` 为既有项目可见轮廓比例设定，不是从截图透视估算的实机比例。按最终非透明轮廓计算缩放，避免因为长臂扩展而将胸腔缩成小骨架。
- 地面基线按脊柱下端、撑地手或灵体消散最低点及具体姿态设置，不能虚构双脚作对齐点。修订战斗缩放或挂点前另读 `角色战斗体型与血条强制规范.md`。
- 呼唤/普通卡图沿用 `1000×760` 横图；约 `250×190` 下能辨认胸腔、前伸长颈与头骨、超长臂及无腿结构。主体的关键骨手、头骨和胸腔不被画布截断。
- 角色选择剪影保留低伏胸腔和长臂轮廓，不使用直立管家或普通持剑骷髅剪影。
- 生成必须传入相应用途的实机参考；旧资产只作构图或尺寸参考，冲突造型不得继承。审批候选仍保存至 `design/卡图预览`，获批准后再覆盖正式资产。

## 8. 强制验收

- [ ] 巨型胸腔拱起、长颈前伸、头骨裸露，比例对应实机参考。
- [ ] 双臂异常修长，肩肘腕掌结构连续，无断轴、额外手臂或肉掌。
- [ ] 肋间透空、下端脊柱可辨，无完整双腿、服装或外持武器。
- [ ] 胸前链条圆饰得到保留，未误画成服装纽扣或领结。
- [ ] 全部材质与配色统一为冷白半透明灵体、蓝灰暗部及克制冷青亮边。
- [ ] 抬臂、低伏或口前能量姿态与对应参考一致，不强制眼眶发射。
- [ ] 用途尺寸、透明通道、朝向、地面基线和缩略图辨识度符合项目规范。
