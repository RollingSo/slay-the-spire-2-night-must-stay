# Night Must Stay 三角色卡图审查与重绘强制规范

> 本规范用于守护者、铁之眼和复仇者的卡图立项、生成、审查、重绘与入库。它补充而不取代各角色身份规范；发生冲突时，尺寸与通用画风以 `Slay_the_Spire_2_卡图生成强制规范.md` 为准，角色身份以各角色专属规范为准。

## 1. 审查顺序

每张卡图必须按以下顺序验收，前一项失败时不得用后续优点抵消：

1. **尺寸与画布**：普通卡为原生 `1000×760` 横图；先古卡为原生 `606×852` 竖图。禁止先生成错误比例再拉伸、硬裁、加黑边或套纸张。
2. **角色身份**：人物、装备、家人和姿态符合对应角色规范，缩至卡牌尺寸后仍能辨认。
3. **机制事件**：画面只表达一个主要规则事件，并能在无标题、无规则文本时与同职业其他卡区分。
4. **缩略图辨识度**：缩至约 `250×190` 后，主要轮廓、动作方向和机制色仍清楚。
5. **画风**：大块平涂、硬边赛璐璐阴影、粗黑形状、有限色板、夸张透视；禁止写实、厚涂概念图和高频材质噪声。
6. **批次差异**：同一职业相邻卡图不得复用相同主轮廓、相同构图骨架或近似主色板。

任何一项失败都进入重绘清单，不以“细节精美”判定通过。

## 2. 无文字机制辨识

- 在绘制前，将卡牌效果压缩为“主体 + 动词 + 结果”三个字段，例如“复仇者拨弦 + 回收幽魂牌影 + 回到手中”。
- 画面只能有一个一级焦点。第二角色、敌人、法阵、建筑和粒子只为一级焦点服务。
- 禁止用通用爆炸、通用光柱、通用人物站姿代替规则事件。
- 同一系列效果必须用稳定的视觉语法，但不能共用同一画面：
  - 防御：前景闭合或偏转形状，受力方向清楚；
  - 回收：从后景/下方返回主体的单向轨迹；
  - 蓄力：未完成状态以琴弦、武器或身体内聚的能量表达，完成效果不得提前发生；
  - 呼唤：复仇者与被选中的家人之间存在明确召唤联系；
  - 共鸣：以琴弦或冲击环向外传播，不能画成泛用闪电；
  - 冻伤：冷白冰晶附着目标或武器，避免与纯雷击同构；
  - 雷击：使用锐利金白或紫金分叉轨迹，并通过落点、次数或范围区分单体、随机与群体。
- 卡牌、卡框、规则文字、UI、数字、Logo 和水印不得出现在卡图内。纸张与卷轴通常也禁止，但“古龙信仰”“癫狂叁指”“黄金律法”“野兽爪痕”属于《艾尔登法环》祷告体系，必须保留既有祷告卷轴主题；卷轴只能作为祷告载体，不得画成尖塔卡牌、卡框或规则文本。

## 3. 三角色身份锚点

### 3.1 守护者

- 鸟首、银灰重甲、高而窄的巨盾、单侧非对称长刃戟、大型棕黑羽翼。
- 长戟的刃、连接件、套筒和杆必须位于连续轴线上；不得截断、漂浮、错接或变成双刃斧。
- 防御反击的伤害动作由盾后短距离前冲和长戟命中承担，除非卡牌本身明确是盾击。

### 3.2 铁之眼

- 苔绿尖兜帽、兜帽下的暗面、白色羽簇、高位箭袋、长弓轮廓。
- 身形纤细、动作克制；只有标记相关近战动作才可突出短刃。
- 远射、移动、标记和毒素必须用不同动作方向与主色区分，禁止整套卡都使用青蓝夜景。

### 3.3 复仇者

- 银白长发、褪色蓝灰花冠、瓷白成年女性面容、灰白长裙与蓝灰披肩、浅色木质古里拉琴。
- 复仇者本人应保持克制、哀悼、人偶般的气质；禁止动漫少女、哥特女巫、黑眼骷髅脸、黑色巨型竖琴。
- 家人必须按 `Revenant_家人视觉规范.md`：海伦为兜帽完全遮脸的纤细刺剑仆从；弗雷德利克为南瓜盔、围裙与南瓜锤构成的魁梧厨师；塞巴斯蒂安为不穿任何服装、无完整下半身、以长臂巨掌为主轮廓的半身骷髅灵体。
- 多名家人同框只用于明确的群体呼唤或共同行动；其他卡只保留与规则直接相关的一名家人。

## 4. 复仇者专属辨识度规则

- 复仇者卡池必须按机制家族规划主色，不得统一为蓝黑墓地：
  - 呼唤/家人：冷白灵体为主，海伦偏深靛蓝/月青，弗雷德利克偏铁锈橙/南瓜金，塞巴斯蒂安偏骨白/深海蓝黑；
  - 回收/死灵：灰绿、骨白、冷青回流轨迹；
  - 蓄力/共鸣：象牙琴木、旧金与青蓝声波；
  - 古龙雷电：金白、紫金或深靛闪电，按单体/群体/次数改变构图；
  - 癫火：橙黄与猩红只用于癫火系列，不能污染其他机制；
  - 冻伤：冰蓝与冷白，必须出现附着、层叠或冻结结果；
  - 防御/恢复：象牙白、浅金、雾蓝的封闭保护形状。
  - 祷告卷轴：古龙信仰使用古龙雷痕，癫狂叁指使用三指癫火烙印，黄金律法使用金色律法环，野兽爪痕使用兽爪印记；四张必须维持同一“展开祷告卷轴”系列语法，同时通过符号、背景主色与边缘能量清楚区分。
- 同一页接触表中，任意两张卡不得同时满足“相同人物位置 + 相同动作方向 + 相同主色”三项中的两项。
- 同一张源图、翻转图、只改色图或只换粒子图不能服务不同卡牌。
- 人物过小、被特效遮脸、琴不可辨认、家人身份错位，均按身份失败处理。

## 5. 构图与安全区

- 一级焦点占画面短边约 45%–75%，不得缩成远景小人。
- 关键头部、手部、武器刃口、盾边、琴框、家人手掌不得贴边或被裁断；离边缘至少保留约 3% 画布尺寸，夸张冲出画面的特效除外。
- 动作方向必须在画面内留出结果空间：攻击前方、回收轨迹终点、召唤物出现位置均不可堵死。
- 背景使用 2–4 个低对比大形状建立场景，禁止用密集城堡、墓碑、碎石或粒子填满所有负空间。

## 6. 批次配色计划

- 每次生成前先列出本批每张卡的主色、强调色、明度结构和主轮廓。
- 同批最多连续两张使用相同色相家族；第三张必须切换主色或明度结构。
- 攻击、技能、能力的画面不能只靠卡框颜色区分。能力牌应优先表现持续状态、仪式或环境改变，攻击牌应有明确命中方向，技能牌应有明确操作或保护结果。
- 审查接触表必须同时查看原尺寸和缩略尺寸；单张放大好看但接触表中混成一片的，仍判定失败。

## 7. 重绘工作流

1. 读取本规范、通用卡图规范及目标角色规范。
2. 从运行时目录生成全量接触表和尺寸/哈希报告。
3. 对每张卡记录：尺寸、身份、机制、缩略图、画风、批次差异六项结论。
4. 为失败项写一条独立提示词；每张卡独立生成，不得用同一生成结果裁成多张。
5. 候选统一保存到 `design/卡图预览/<角色>_<日期>/`，不得直接覆盖运行时资产。
6. 候选通过尺寸、缩略图和四角/边缘检查后，生成带文件名的审批接触表。
7. 只有获得用户批准后，才覆盖 `*_assets/cards/`、触发 Godot 导入并导出模组。

## 8. 强制验收表

- [ ] 普通卡 `1000×760`，先古卡 `606×852`，无拉伸或黑边。
- [ ] 角色与装备符合专属规范，人物没有肢体、手指和武器连接错误。
- [ ] 不看标题也能说出画面的主要规则事件。
- [ ] `250×190` 缩略图下主轮廓和动作方向清楚。
- [ ] 使用平涂、硬边、粗轮廓和有限色板，而非写实/厚涂。
- [ ] 同职业卡图不存在相同源图、镜像、换色或近似构图复用。
- [ ] 卡图内没有卡牌、纸张、UI、文字、Logo 或水印。
- [ ] 祷告卷轴例外仅限古龙信仰、癫狂叁指、黄金律法和野兽爪痕；卷轴上没有可读规则文字，也不会被误认成卡牌。
- [ ] 关键身份部位和武器未被画布截断。
- [ ] 候选位于审批目录，尚未覆盖正式资产。
