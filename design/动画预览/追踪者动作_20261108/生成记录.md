# 追踪者战斗动作补帧

- 使用内置 imagegen 生成两张真透明战斗姿态：`袭击桩柱姿态.png`、`钩爪射击姿态.png`。
- 身份参考：`wylder_assets/approved_sources/idle.png`。
- 装置参考：`design/卡图预览/空袭桩柱_金色窄臂_1000.png` 与 `design/卡图预览/追踪者新卡_20261106/钩爪射击.png`。
- 袭击桩柱姿态不包含爆炸或飞行投射物；钩爪姿态包含三爪钩和连续细绳。两图四角 alpha 均为 0。
- 运行时按非透明高度分别使用 `0.294` 与 `0.344` 缩放，使脚底与现有约 295px 的战斗人物高度对齐。
