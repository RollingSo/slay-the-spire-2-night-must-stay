# HE03 攻击B `attack_b`：后撤步反击（HelenRetreat）

对应代码里的 `HelenRetreat` 行动：3 伤 + 1 能量。与 A（`HelenStepStrike`，3 伤 + 抽牌）每回合二选一。

## 用法

1. 即梦上传 `HE03_攻击B_首帧.png` 作为参考图／首帧。
2. 提示词全文复制 `HE03_攻击B_即梦提示词.txt`。
3. 720p、5 秒档生成，把 mp4 发回。

## 首帧来源

`revenant_assets/families/helen.png`（512×512 真透明）合成到 `#263340`，整体放大到 1024×1024。

## 与 A 的区别（生成后必须一眼能分辨）

| | A 上步突刺 | B 后撤反击 |
|---|---|---|
| 位移 | 向前 | **向后（画面左侧）** |
| 重心 | 前压 | **后仰** |
| 剑路 | 斜向上挥 | **浅而快的下切** |

B 最容易被模型做反——它可能本能地“向前攻击”。提示词里把“向画面左侧后移”“上身后仰”“抬脚退半步”写了三处，并且明确“不是向前冲锋”。

## 提示词里刻意不写角色名

全文不出现「海伦」，身份靠结构描述：尖顶遮面兜帽、宽袖束腰短衣、胸前细链圆饰、肩背破碎披布、骨骼前臂、完整骨骼双腿、一把细长直剑。

## v1 失败记录（2026-10-22）

第一次生成的视频（`~/Downloads/HE03.mp4`）**做成了向左转身挥剑**：f36 起人物整体转向、剑横挥，f75 之后甚至移出画面左边缘（左边界到 0）。脸没问题，但动作不是后撤；倒放等于反向转身，仍然不是后退。

修正：提示词加入朝向锁「胸口、肩膀与胯部始终朝向画面右侧的敌人，不转身、不转体、不绕圈」，剑限制成「一次短促下切，不横挥、不挑起、不绕过头顶」，后退改为「左脚退半步、另一脚跟半步」的明确步法。

## 生成后检查点

- 人是不是**真的往后退了**，而不是原地挥剑或向前扑
- 兜帽有没有露脸、头和兜帽有没有分离
- 剑是否只有一次下切、握在手里不换手
- 撤步是抬脚迈步，不是双脚贴着地面平移
- 结束前是否踏回原位（这条关系到切回待机时会不会错位）

## 目标时长

游戏等待 0.6–0.9 秒。生成 5 秒，处理时取「撤步出剑 + 保持」那一段，回位段可以压缩或截断。
