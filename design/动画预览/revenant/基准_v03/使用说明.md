# 基准 v03：18 个动作，画布随动作、锚点入库

## 规则变更（v03）

v02 把所有动作塞进同一张固定画布（家人 512×512、复仇者 256×256）。动作一旦伸展（海伦举剑、塞巴斯蒂安仰天长啸）就会被裁掉——v02 的 HE02 剑尖实际已经被切掉 5px。

v03 改成：**每个动作按自己的并集包围盒开画布**，画布尺寸与锚点写进 `.res` 的 meta：

| 项 | v02 | v03 |
|---|---|---|
| 画布 | 全部固定 512×512 / 256×256 | 该动作并集包围盒 + 8px 边距 |
| 定位 | 硬编码 `256`（=512/2） | `canvas` + `anchor` 两个 meta |
| 接入 | 固定公式 | `sprite.Offset = (W/2−ax, H/2−ay)`，节点固定在地面线 |

**尺寸基准仍然按角色分别取自游戏内**，没有统一成同一个值：

| 角色 | 画布高基准 | 依据 |
|---|---:|---|
| 海伦 | 344 | `families/helen.png` 包围盒，运行时 `204×0.8/344` |
| 弗雷德利克 | 325 | 同上，`204×1.0/325` |
| 塞巴斯蒂安 | 331 | 同上，`204×1.2/331` |
| 复仇者 | 216 | rig `0.21×1.2×0.6447` |

## 接入

```csharp
Vector2 size = frames.GetMeta("canvas");
Vector2 anc  = frames.GetMeta("anchor");
sprite.Offset = new Vector2(size.X / 2 - anc.X, size.Y / 2 - anc.Y);
_familyVisual.Position = new Vector2(0, FamilyGroundY);
```

家人资源已复制到 `revenant_assets/families/animations/<角色>/`：
`idle.res` / `attack_a.res` / `attack_b.res`（尚未生成）/ `hurt.res`。
`family_animation.gd` 按 clip 读这些文件，`AttackA`/`AttackB` 分别对应 First/Second 两种行动。

## 已知问题

1. **Godot 版本**：`.res` 由本机 4.7.2 保存，项目目标 4.5，正式接入前需用 4.5 重新打包复载。
2. **SE04 中立高 312**（基准 331）：受击起始姿态本身比待机塌 6%，同相机距离下应为 312，不要抬到 331。
3. **时间适配未做**：HE02 含 1.4 秒空举、RV02 4.58 秒、SE02 4.88 秒都远长于游戏等待。
4. **RV09 尺寸基准不同**：篝火待机按 rest_site 渲染尺寸 296px 的 1.6× 制作（474px 可见高），不是战斗的 216px；接入时篝火场景用约 0.625 缩放绘制，锚点落在 Sprite 原点。
5. **SE03 是抽取段**：源视频 f16–f44（举臂→砸下→伏低），后半段角色站起来了，已丢弃；末 2 帧混回起始姿态。
6. **接缝**：HE02/HE04/SE04 首帧与待机剪影 IoU 在 0.67–0.78，切进待机会有轻微形变。
