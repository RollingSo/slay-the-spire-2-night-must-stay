# 女爵：动画制作清单与素材目录

日期：2026-10-25。协作分支：`animate-0.1`。

用户确认按本清单规划女爵动画，并将清单上传代码仓。范围为 **8个基础动画＋2个特色扩展**；本次登记清单与目录，尚未生成新素材或接入正式 Mod。动作细节与时长为制作建议，逐项预览后确认。

## 1. 制作依据与身份基准

开始制作前完整阅读：

- [角色战斗动画制作与 Mod 适配工作流](../../角色战斗动画制作与Mod适配工作流.md)
- [女爵视觉形象强制规范](../../duchess/女爵视觉形象强制规范.md)
- [角色战斗体型与血条强制规范](../../角色战斗体型与血条强制规范.md)，尤其女爵与铁之眼相对体型条款。

参考铁之眼五套战斗序列（待机、射箭、小刀、施法／强化、受击）与复仇者本人8个独立视频的分工方式。女爵重点表现轻巧、精准、克制和贵族仪态。

正式参考图：

- 战斗：`duchess_assets/combat_rig/duchess_combat_character.png`
- 商店：`duchess_assets/merchant/duchess_merchant.png`

保持侧分银白短发、贴脸黑色雕纹面具、深海军蓝长外套、白色领巾和手套、象牙白长裤、黑色长靴与暗酒红内衬。默认武器为单把短直刃短剑。制作前实际查看对应正式图，按角色自身左右锁定持剑手别，全程不换手。

## 2. 基础动作：8个独立视频

表内时长是剪辑后完整动作的建议时长，不是生成平台输出长度，也不是游戏命令等待。

| 编号 | 动作／文件名 | 用途与动作要求 | 建议完整时长 | 循环 | 状态 |
|---|---|---|---|---|---|
| DU01 | 战斗待机 `combat_idle` | 沿用正式持短剑姿态；轻微呼吸、重心微动，前发与外套下摆低幅摆动，保持警觉 | 3–4秒 | 是 | 待制作 |
| DU02 | 短剑攻击 `dagger_slash` | 短促起手、身体前送，完成一次精准斜切后收剑归位；肩、腰、手臂共同参与 | 0.8–1.1秒 | 否 | 待制作 |
| DU03 | 闪避／防御 `dodge_defend` | 小幅侧身撤步、收肩避让，持剑手保持控制，迅速恢复战斗基准；与被动受击区分 | 0.6–0.9秒 | 否 | 待制作；闪避相关入口待核对 |
| DU04 | 施法／能力 `cast` | 空手做一次清晰克制的抬手或翻掌手势，持剑手稳定，完成后回到待机；第一版覆盖攻击法术、强化与时间能力的身体动作 | 1–1.3秒 | 否 | 待制作；具体入口待映射 |
| DU05 | 受击 `hurt` | 肩腰短促后撤、膝部缓冲、衣摆跟随，随后重新站稳 | 0.6–0.9秒 | 否 | 待制作 |
| DU06 | 死亡 `death` | 失去支撑、屈膝下沉后倒地，保留稳定末态；具体倒地方向先做姿态确认 | 2–2.5秒 | 否 | 待制作；末态待确认 |
| DU07 | 商店待机 `merchant_idle` | 使用商店正式图姿态；呼吸、手部与衣料低幅运动 | 3–4秒 | 是 | 待制作 |
| DU08 | 篝火待机 `camp_idle` | 使用篝火正式图姿态；轻微呼吸，头部与手部放松，衣料缓动 | 4–5秒 | 是 | 待制作 |

战斗非循环动作除死亡外，首尾衔接同一份DU01基准姿态；商店、篝火各自建立独立基准。

## 4. 触发与时间适配

2026-10-25仓库静态核对结果：

- `src/Core/Models/Characters/Duchess.cs`：默认Attack等待0.15秒、Cast等待0.25秒。短起手、早释放，后半段用于收招；不得为等待完整视频而延长既有游戏命令。
- `src/Core/Models/Cards/DuchessCard.cs`：`OnPlay`在`GainsBlock`成立时调用`DuchessAnimationPatch.PlayBlock`，当前已有独立Block入口。闪避相关效果是否触发DU03，后续逐项核对，不能直接按名称推断。
- `src/Core/Patches/DuchessAnimationPatch.cs`与`duchess_assets/combat_rig/duchess_combat_rig.gd`：当前转发Attack、Hit、Cast、Block、死亡及复活等入口；新清单尚未替换现有播放实现。
- 攻击法术与时间能力的身体动作属于本清单的拟定分配，接入前建立“实际命令入口 → 触发 → 序列”映射，逐项核对等待、音效与特效。

每项分别记录源视频时长、剪辑后资源时长、释放／峰值帧与时间、实际命令等待，以及正常／快速／瞬时模式下的实际表现时长。预览连续重播、受击打断、死亡锁定与复活恢复。

身体视频只表现人物和随身装备。刀光、魔法剑、钟面、残影和隐身效果由游戏侧管理，避免重复烘焙到人物帧中。

## 5. 素材目录与命名

女爵动画素材统一存放在本目录：`design/动画预览/duchess/`。文件平铺，以编号、动作名和用途区分，不按任务或版本另建嵌套目录；版本与日期追加到文件名。

命名格式：`<编号>_<动作名>_<用途>_<版本或日期>.<扩展名>`，例如：

- `DU01_战斗待机_首帧_v01.png`
- `DU01_战斗待机_即梦提示词_v01.txt`
- `DU01_战斗待机_源视频_v01.mp4`
- `DU01_战斗待机_预览_v01.gif`
- `DU01_战斗待机_使用说明_v01.md`
- `DU01_战斗待机_透明帧_v01_000.png`
- `DU01_战斗待机_图集_v01_00.png`
- `DU01_战斗待机_SpriteFrames_v01.res`
- `DU01_战斗待机_验证记录_v01.json`

说明中登记正式参考图路径与SHA256、平台／模型及参数、负责人、采用版本、首尾姿态、循环区间、释放标记、当前阶段与待办。大源视频与母版帧按仓库素材策略处理；未进入Git的文件须登记可获取位置，不将本机路径视为已上传。

状态按阶段更新：`待制作 → 参考确认 → 视频生成 → 视频待审 → 视频通过 → 透明序列 → 时间适配 → 引擎验证 → 实战验证`。素材通过、正式接入、导出安装与实战验证分别记录。

## 6. 制作顺序

先做DU01待机和DU02短剑攻击，锁定形象、动作气质、持剑手别、脚底锚点、活动范围与首尾姿态，再继续：

`DU03闪避防御 → DU04施法 → DU05受击 → DU06死亡 → DU07商店 → DU08篝火`。

DU09、DU10在基础动作确认后评估独立制作。各动作使用稳定画布与共同锚点，以最终非透明可见边界核对体型；女爵遵守既有相对体型，不直接套用铁眼或复仇者的源画布尺寸。
