# 能力图标生成强制规范

本规范适用于所有角色的能力、状态、行动预告与机制图标。能力图标必须同时适配战斗状态栏的小图标、悬停解释框图标以及能力触发闪烁。

## 视觉要求

- 正式资源统一为 `256×256` PNG，使用粗黑轮廓、大面积清晰色块、硬边赛璐璐明暗和单一可读主体。
- 缩小至 `32×32` 时仍须能辨认核心动作或机制；禁止依赖文字、数字、细碎纹理或完整人物场景。
- 同一机制的紧凑图标与解释框图标必须引用同一正式资产，不得继续使用占位图或无关能力图标。

## 透明通道强制要求

- 图标背景必须为真实 Alpha 透明，禁止洋红底、黑底、白底、棋盘格或任何实色方形底。
- PNG 必须保存为带 Alpha 的 `32bpp ARGB/RGBA`；不得以颜色键、混合模式或运行时材质伪造透明。
- 四个角像素的 Alpha 必须全部为 `0`。主体外的空白区域不得残留半透明色块、生成式背景光晕或脏边。
- 缩放和导出时必须保留透明通道，并使用高质量插值；不得先合成到不透明画布再缩小。
- 导入 Godot 前必须以像素检查确认：尺寸为 `256×256`、格式含 Alpha、四角 Alpha 为 `0`。任意一项不满足即退回重做。

## 接入与校验

- 每个能力必须拥有与模型 ID 同名的独立图标资源和 `images/atlases/power_atlas.sprites/*.tres` 映射。
- 检查能力模型、本地化键、PNG、AtlasTexture 映射四者是否一一对应，避免多个无关能力误用同一占位图。
- 导出前必须完成 Godot 资源导入，并在 PCK 中确认新图标映射已被打包。
