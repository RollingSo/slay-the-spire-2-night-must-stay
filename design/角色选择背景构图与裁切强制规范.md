# 角色选择背景构图与裁切强制规范

> 本规范适用于守护者、铁之眼、复仇者及后续角色的角色选择背景。验收对象是游戏中的最终可见画面，不是单独打开的源 PNG。

## 1. 固定画布与场景布局

- 正式背景统一使用 `2560×1200` PNG。
- 背景根 `Control` 必须以视口中心为锚点，并使用 `offset_left=-1280`、`offset_right=1280`，禁止使用会把画布左对齐的 `-960/1600` 等偏移组合。
- `TextureRect` 保持全画布铺设。更换人物站位时，必须同步修正待机 Shader 的 `body_center` 与 `secondary_center`。

## 2. 16:9 实际裁切安全区

- `2560×1200` 的宽高比为 `2.133:1`，而标准游戏窗口约为 `1.778:1`。居中显示时，左右各约 `320px`、即画布宽度 `12.5%` 会离开最终可见区域。
- 因此中央 `x=12.5%–87.5%` 才是标准 16:9 的基础可见区；不得把脸、胸腹、持武器手、主要武器头、琴身、盾牌识别轮廓等关键内容放在此范围之外。
- 为适配窗口缩放和 UI 遮挡，关键主体建议进一步收进 `x=15%–85%`；右侧至少保留 `12.5%` 的纯背景呼吸空间。
- 顶部与底部允许裁切长武器末端、裙摆或装饰，但不能裁切头部、手部动作和角色身份核心。

## 3. 左侧 UI 安全区

- 左侧角色姓名、生命、遗物和说明面板所占区域必须以游戏截图复核。
- 人物脸、发光眼睛、胸腹主质量与主武器焦点不得进入最终画面的左侧信息面板；低对比羽翼、披挂、灵体剪影可以作为背景经过。
- 不能通过把人物贴到最右边来换取左侧空白。应缩小或重新构图，使“左侧 UI 安全区”和“右侧裁切安全区”同时成立。

## 4. 强制验收流程

1. 检查源图为 `2560×1200`，且人物在源图中没有被边缘预先截断。
2. 检查场景根节点为居中的 `-1280/1280` 布局。
3. 按中央 `12.5%–87.5%` 可见区叠加裁切框，确认身份核心均在框内。
4. 在实际 16:9 游戏角色选择界面截图中复核左侧 UI、右侧按钮和人物完整性。
5. 超宽屏、窗口化或云游戏缩放只作为附加检查，不能替代标准 16:9 验收。

只检查源图、只修改 Shader 中心、或只在编辑器中查看场景，均不能视为完成。
