# 《Elden Ring: Nightreign》守护者角色设计与动作强制规范

> 本规范用于守护者 Mod 的卡牌设计和卡图生成。角色事实以官方资料与官方立绘为依据；卡图绘制方式仍须同时遵守 `Slay_the_Spire_2_卡图生成强制规范.md`。

## 1. 官方依据

- Bandai Namco 官方角色页：`https://en.bandainamcoent.eu/elden-ring/elden-ring-nightreign/characters/guardian`
- Bandai Namco 官方 Advanced Tips：`https://en.bandainamcoent.eu/elden-ring/news/advanced-tips-elden-ring-nightreign`
- Bandai Namco 官方 Gameplay Guide：`https://www.bandainamcoent.com/games/nightreign/gameplay-guide`
- 官方角色立绘临时研究文件：`.tmp/guardian-study/GUARDIAN-render.png`

官方能力定义：

- **Steel Guard**：Plant feet and brace with shield for a more powerful guard。
- **Whirlwind**：以羽翼卷起旋风，牵引敌人并扫开轻型投射物。
- **Wings of Salvation**：跃起俯冲，落地后建立保护区域。

官方进阶说明还指出：从普通格挡切换到 Steel Guard 约有半秒空档，因此它是一个明确的“切换动作”，不是天然常驻盾墙。

## 2. 角色身份

守护者是来自翼之国度的 Pinionfolk 骑士，不是戴鸟盔的人类，也不是神圣天使。

必须保留的身份层级：

1. **真实鸟类头部**：棕褐羽冠、浅灰弯钩鸟喙、深色颈羽；脸部不是金属头盔。
2. **大型棕黑羽翼**：羽翼属于身体，不是披风装饰。
3. **高大厚重体型**：宽肩、厚胸、稳定下盘，整体比普通骑士更高更沉。
4. **骑士队长气质**：克制、警觉、承担责任，不表现野兽狂怒。

卡图风格化时，鸟头至少保留“浅色弯喙 + 棕褐头羽 + 深色颈羽”三段结构。

## 3. 默认服装与装备

### 3.1 银色重甲

- 主体为旧银色板甲，不是全身封闭式铠甲。
- 胸前有向下收束的鸟羽/鸟喙形金属胸饰。
- 肩部和上身混合银甲、黑铁结构与棕色皮带。
- 腰部以下是灰白色分片裙甲/布甲，形成多个向下尖角。
- 装甲华丽但不金碧辉煌；视觉基调是古老、磨损、严谨。

转译成《杀戮尖塔 2》画风时，应把真实细节压缩成：

- 银白亮面；
- 蓝灰中间面；
- 近黑结构面；
- 少量棕色皮带或羽毛色。

### 3.2 巨盾

- 默认盾是高而窄的长形巨盾，而不是圆盾或宽厚塔盾。
- 盾体呈银黑色，顶部和侧边带尖角、缺口或羽片般的锐利轮廓。
- 盾牌高度接近躯干，是守护者最重要的防御符号。
- 举盾时盾面应遮住胸腹大部，但鸟头、肩线或羽翼仍需留下身份线索。

### 3.3 长戟

- 默认长柄武器比例很长，刃部宽大并带鸟翼般的弯曲锐角。
- 后续统一以 `design/卡图预览/2026-07-26_攻守易形重绘/offense_defense_shift_selected_1000x760.png` 中的金色长戟为标准轮廓。
- 标准戟头由四个清晰形状组成：沿长杆继续前伸的细长中央刺、根部的锐角连接块、下侧一片宽大且向后回钩的鸟翼形主刃，以及上侧一片明显更小的尖翼。
- 中央刺与下侧主刃之间必须保留醒目的弧形镂空负形；主刃外缘向下收成锐尖，使缩略图首先读成神鹰专属的修长钩刃戟，而不是普通长矛。
- 上下刃必须保持明显不等大，整体轮廓非对称；不得把它简化成单纯枪头，也不得画成两片等大的对称月牙刃。
- 防御牌中长戟可以只保留一段斜线轮廓，不能与盾牌争夺焦点。
- 攻击牌才突出长戟的完整刃型和运动轨迹。

禁止形状：

- 左右对称的双斧刃；
- 围绕杆头展开的四向尖刺；
- 剑身直接装在长杆上的“大剑枪”；
- 两片大小相当的月牙刃或鸟翼刃；
- 没有下侧宽大钩刃和弧形镂空、只剩中央尖刺的普通枪头。

### 3.4 羽翼

- 羽翼为棕褐至黑褐色，外缘羽片宽大、层叠。
- 普通卡不需要总是完整展开；一侧翼根或几块大羽片足以建立身份。
- 防御姿态中羽翼更适合作为后方收拢的稳定三角形，而非神圣展开。

### 3.5 角色选择界面

- 必须直接以官方 `GUARDIAN-render.png` 的服装分层为身份基准，保留网状银色肩甲、鸟羽形长胸饰、交叉皮带、腰间结饰与多片尖角长裙甲，不能简化成普通封闭胸甲鸟骑士。
- 鸟头相对高大躯干应偏小且写实，颈部细长；禁止放大成卡通鹰头。
- 至少一侧大型棕黑羽翼必须形成宽阔剪影，并以低幅度张合表现待机动作。
- 呼吸与羽翼动作应缓慢、沉稳，粒子风应沿横向掠过，不能让整幅画面明显摇晃。
- 角色选择背景统一按原版 `2560×1200` 画布与左侧信息面板安全区构图；原版角色场景普遍使用相同的 `SpineSprite` 基准位与缩放，新增角色不得仅凭“贴边显得更大”改变站位。
- 守护者的头部视觉中心应位于画布宽度约 `54%–61%`，胸腹主质量中心位于约 `55%–64%`；必须同时遵守 `角色选择背景构图与裁切强制规范.md` 的中央安全区，右侧至少保留 `12.5%` 画布宽度。盾牌、羽翼与武器的身份识别部分也必须留在最终 16:9 可见区域内，不得依赖源图边缘构图。
- 左侧约 `10%–38%` 为姓名、生命、遗物与说明文本的主要安全区；守护者的脸、胸甲和持武器手不得进入该区。
- 角色站位变动后，待机着色器的 `body_center`、翅膀或披挂的 `secondary_center` 必须按同一像素位移同步修正，禁止出现人物已经移动但呼吸形变仍留在旧位置的情况。
- 长戟头、根部连接块、套筒和杆身必须共用一条连续轴线；戟头中央柄舌应收窄后完整插入圆柱套筒，并由短护套或金属箍过渡，不得悬空、错位、重影或像贴图叠在杆身旁。

## 4. 动作性格

守护者的动作核心是“以重量换取控制”：

- 起动比轻型角色慢，但每一步都有明确重心转移。
- 防御不是静态摆拍，而是把身体移动到盾后。
- 盾牌先建立安全平面，身体随后压入该平面。
- 翅膀用于平衡、制动、制造风压和保护，而不是轻盈飞舞。
- 反击来自动作链：格挡 → 吸收冲击 → 盾后重心回弹 → 向目标短距离冲刺 → 长戟重击。

卡牌设计应优先从这种动作链切片，而不是反复画“拿盾站立”。

### 4.1 防御反击的准确动作

“防御反击”不是盾击。盾牌只负责完成格挡与制造反击窗口；真正的伤害动作是守护者从盾后向目标短距离冲刺，并用长戟进行一次沉重打击。

视觉记忆点：

- 盾牌退到身体侧后方或作为前一拍的残留轮廓，不能成为撞击敌人的主体；
- 躯干与前脚沿低矮、短促的水平冲刺线前送，后脚和收拢羽翼负责制动；
- 长戟的单侧宽刃占据主要对角线，在冲刺末端完成横斩、斜劈或下砸；
- 敌人受击点位于戟刃或戟刃轨迹末端，不位于盾面；
- 防御反击牌之间用冲刺距离、出刃角度、敌人受击状态与冲击规模区分，而不是反复画不同强度的盾击。

禁止表现：

- 用盾面撞飞敌人；
- 怪物拳头或头部撞上盾面后直接被判定为反击画面；
- 盾牌居中遮挡全部动作，而长戟只在背景中静止竖立；
- 把短距离冲刺画成长距离奔跑、飞扑或腾空突进。

## 5. Steel Guard / 强力防御的准确动作

### 5.1 触发逻辑

Steel Guard 是在普通举盾格挡时，通过一次带方向的闪避/垫步输入进入的强化架势。

动作分为四拍：

1. **普通格挡**：盾已在左侧或身体前侧，但重心仍可移动。
2. **垫步切换**：脚向侧前方短促移动，身体不是翻滚；此时存在短暂转换空档。
3. **盾面送正**：持盾臂把高盾推到正面，盾面更垂直、更完整地覆盖躯干。
4. **压低扎根**：后脚跟进，双膝弯曲，肩背压入盾后，进入更强格挡但失去奔跑能力。

因此 Steel Guard 的视觉记忆点是：

> 横向位移线 + 前后错开的脚步 + 正在抬正的高盾 + 身体向盾后收拢。

它不是：

- 用脚猛踩地面；
- 盾击地面；
- 单膝跪地；
- 原地召唤冲击波；
- 展开魔法盾墙。

### 5.2 “踏地架势”的卡图切片

这张卡应抓取第 2–3 拍之间：守护者刚完成短促垫步，前脚横向擦过地面，巨盾已经从侧面抬向正前方，后脚尚在收稳。

画面必须让玩家先读到“移动中进入防御”，而不是“已经站稳防御”。

推荐视觉构成：

- 高盾占画面右侧或中央约 45%–55%，形成最强大轮廓；
- 鸟头从盾上缘后方露出，视线越过盾沿观察敌人；
- 前脚与后脚错开，脚下只出现一条横向擦地色块，不画爆炸或地裂；
- 躯干沿垫步方向倾斜，持盾肩向前压；
- 一侧收拢羽翼在身后形成深棕黑三角形；
- 长戟只作为后方斜线或被裁切的次要形状；
- 从画外射来的 2–3 根白色攻击箭头可以逼近盾面，但尚未撞击，以强调“抢先进入架势”。

## 6. 三类能力的视觉区分

### Steel Guard

- 关键词：垫步、举盾、收身、扎根、守反。
- 形状：高盾的竖直平面、错步形成的横向运动。
- 特效：少量擦地线、轮廓光、即将接触的攻击箭头。

### Whirlwind

- 关键词：单翼横扫、羽片、旋风牵引、扫开投射物。
- 形状：一条巨大弧线，羽翼比盾牌更重要。
- 特效：宽阔风带和被偏转的箭矢，不画普通龙卷风法术。

### Wings of Salvation

- 关键词：升空、折翼俯冲、重落、保护区域、救援。
- 形状：垂直俯冲箭头与落点圆域。
- 特效：金白保护区域可以出现，但必须在落地后，不与 Steel Guard 混用。

## 7. 后续卡牌设计原则

- 卡牌机制优先映射到守护者的动作链，而不是抽象魔法。
- 防御牌之间要区分：进入架势、承受撞击、保护队友、成功格挡、守势反击。
- 攻击牌强调长戟的距离和重量，避免普通剑士动作。
- 翼相关牌要体现真实羽翼的重量、风压和制动作用。
- 只有终极或高稀有度卡才使用大规模金色保护领域。
- 每张卡只突出盾、戟、翼三大符号中的一个主符号，其余作为身份辅助。

## 8. 生成前检查

- [ ] 鸟头是真实头部而非鸟形头盔。
- [ ] 巨盾是高而窄的锐角长盾。
- [ ] 铠甲为银白、蓝灰、近黑和少量棕色的硬边分面。
- [ ] 羽翼是棕黑色身体结构，不是披风或天使光翼。
- [ ] 动作体现重量转移，不是静态角色立绘。
- [ ] 当前卡牌只突出一个能力动作切片。
- [ ] 同时符合《Slay the Spire 2》卡图强制规范。
