# 《Elden Ring: Nightreign》守护者（Guardian）角色设计分析报告

> **状态：已被新版强制规范取代。** 本报告中的早期统一 Prompt 会生成写实厚涂风格，且对 Steel Guard 的动作描述不够准确。后续角色与动作设计请统一遵循 `design/Guardian_角色设计与动作强制规范.md`，绘制方式同时遵循 `design/Slay_the_Spire_2_卡图生成强制规范.md`。

## 1. 角色定位

守护者（Guardian）来自《艾尔登法环：黑夜君临》（ELDEN RING
NIGHTREIGN），是 Nightfarer 中承担前排防御与团队保护职责的角色。

官方定位： - 高防御能力角色 - 使用巨大盾牌承受猛烈攻击 -
擅长保护队友与控制战场

核心身份：

> 一名来自翼族国度的重装翼人骑士，以自己的身体成为战场上的城墙。

参考： Bandai Namco 官方角色介绍：
https://en.bandainamcoent.eu/elden-ring/elden-ring-nightreign/characters/guardian

------------------------------------------------------------------------

# 2. 背景与身份分析

守护者不是普通人类骑士，而是具有鸟类特征的 Pinionfolk（翼族）。

角色关键词：

-   翼族战士
-   前任队长
-   战争幸存者
-   守护同胞的盾牌
-   重伤仍继续战斗

视觉核心：

不是"圣骑士"。

而是：

"经历战争后仍承担责任的古老守卫者"。

------------------------------------------------------------------------

# 3. 外观设计分析

## 3.1 身体特征

核心：

-   鸟类头部
-   羽翼
-   强壮躯体
-   重甲覆盖

设计目的：

形成非人类英雄辨识度。

禁止：

普通欧洲骑士脸。

必须保留：

-   鸟喙轮廓
-   羽毛结构
-   翼部存在感

------------------------------------------------------------------------

# 4. 装备设计分析

## 巨盾

守护者最核心视觉符号。

作用：

-   防御
-   阻挡
-   保护

卡图表现：

不要只是拿盾站立。

应该表现：

-   盾牌撞击地面
-   盾墙展开
-   保护队友
-   抵挡巨大攻击

------------------------------------------------------------------------

## 长戟

官方武器偏好为长柄武器。

视觉语言：

-   控制距离
-   守住阵线
-   反击

动作：

推荐：

-   横扫
-   插地
-   旋转
-   格挡反击

避免：

普通刺击姿势。

------------------------------------------------------------------------

## 银色重甲

颜色：

主体： - 银白 - 灰黑阴影

辅助： - 暗金 - 冷蓝

感觉：

古老、沉重、神圣但衰败。

------------------------------------------------------------------------

# 5. 技能视觉分析

## Steel Guard

被动：

强化盾牌防御。

视觉：

关键词：

-   扎根
-   不可移动
-   城墙
-   铁壁

卡图：

守护者单膝压地，盾牌形成壁垒。

------------------------------------------------------------------------

## Whirlwind

技能：

挥动翅膀制造旋风。

视觉：

不是普通风元素。

应该体现：

"巨大的羽翼产生战争风暴"。

元素：

-   羽毛飞散
-   风刃
-   敌人被卷起
-   银色气流

------------------------------------------------------------------------

## Wings of Salvation

终极技能：

跃起后俯冲，创造保护区域。

视觉定位：

守护者最高级象征。

关键词：

-   天空
-   羽翼展开
-   神圣降临
-   救援

适合作为稀有卡视觉参考。

------------------------------------------------------------------------

# 6. 卡图设计方向

## 核心主题

三角结构：

翼 → 天空力量

盾 → 守护职责

长戟 → 战斗能力

每张卡至少突出其中一个。

------------------------------------------------------------------------

# 7. 色彩规范

主色：

银白： 重甲、荣耀

深蓝： 夜晚、风暴

金色： 救赎、神圣力量

黑灰： 战争、伤痕

------------------------------------------------------------------------

# 8. 动作设计规范

攻击牌：

强调：

-   武器运动轨迹
-   冲击方向
-   敌人反馈

例：

长戟横扫产生银色弧光。

------------------------------------------------------------------------

技能牌：

强调：

-   防御结构
-   战术动作
-   保护范围

例：

盾牌展开形成羽翼形屏障。

------------------------------------------------------------------------

能力牌：

强调：

-   持续领域
-   神秘力量

例：

守护者站在暴风中心，羽翼形成保护领域。

------------------------------------------------------------------------

# 10. 制作限制

所有守护者Mod卡图：

必须：

-   保留翼族身份
-   保留重甲重量感
-   保留守护者职责
-   保留黑夜君临世界观

避免：

-   普通人类骑士
-   圣光天使风格
-   现代幻想铠甲
-   过度华丽魔法少女化

------------------------------------------------------------------------

# 11. 最终视觉定位

一句话总结：

> 一只来自黑夜尽头的翼族战争老兵，用巨盾挡住毁灭，用羽翼带来救赎。
