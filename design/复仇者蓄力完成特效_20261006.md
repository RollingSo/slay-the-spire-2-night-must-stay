# 复仇者蓄力完成反馈（待实测）

推送前已接入远端最新 main：远端已有 0.3.8 版本和第八种蓄力牌「古龙雷击」，同样经过统一完成通知并通过检查。保留远端现有版本号。下文的七种牌和 0.2.13 本地包记录属于初始基线验证。

统一接入 RevenantSummonManager.NotifyChargeCompleted，七种蓄力牌都在 ChargeComplete 从未完成转为完成后调用。准备仪式和和声等卡牌通过 CompleteCharge 触发同一通知；已完成的牌再次调用时由原有状态检查返回，避免重复反馈。

完成瞬间在复仇者 VfxSpawnPosition 播放 0.65 秒的紫白灵光：光圈内收，核心短闪，四个微小光点上升。沿用现有 refined 图集、原生 GPU 粒子与 Shader，主帧约 137×126，不修改人物体型、位置、卡牌规则或伤害。

同一节点 _Ready 的 OnStart 播放游戏内置 dark_orb_evoke.mp3，音量 0.55。没有蓄力前摇、攻击出手或回手时的额外播放；完成多张牌时，每张实际状态转变都获得反馈。测试模式、无交互模式、战斗结束或角色已死亡时跳过画面与声音。

主工程与预览工程编译通过；七种状态转变、共享入口、卡牌辅助入口以及原有复仇者路由测试通过。现安装游戏版本的 Sentry 依赖已补入测试工程。PCK 资源预览通过可见性、0.65 秒生命周期与节点释放检查；音效从游戏 PCK 加载成功（约 1.415 秒）。预览日志无 C#、Shader 编译或节点泄漏错误，环境的根证书/shader cache 提示不影响渲染。
