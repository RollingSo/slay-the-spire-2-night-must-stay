# 女爵伤害接口兼容修复

旧 API 的伤害加算/乘算钩子为五参数；当前安装版增加第六参数 CardPlay。

隐匿与零费攻击加成不再直接重写易变签名，改用项目既有 DamageModifierBranchCompatibility 运行时桥接。补丁只处理对应女爵能力，其余原版/其他能力继续原流程；不修改卡牌文本、数值或机制。

保留条件：隐匿仅增强能力拥有者的有效攻击（×1.25）；零费攻击加成按 EnergyCost.GetResolved() 判断，包含减到零费与本回合设为零费的攻击，排除技能、无加成伤害和其他攻击者。

验证：当前安装版六参数 API 和仓库旧版五参数 API 均编译通过。使用实际 Harmony 补丁后的引擎伤害接口执行同一份模组 DLL，两个环境均通过90张女爵模型/升级及伤害条件测试。未导出安装，未提交推送。
