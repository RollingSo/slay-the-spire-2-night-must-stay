## 自动化证据

- `tools/duchess_model_tests`：本机原版API下64牌实例化、基础/升级变量、初始牌组、核心规格、移除旧机制和全部女爵Harmony补丁绑定。

- `validate_duchess_assets.ps1`：正式PNG尺寸、Alpha与场景依赖检查。
- `validate_duchess_resources.gd`：源资源与导出PCK加载检查。

## 实机项目（待执行）

- [ ] 角色选择：女爵名称、介绍、初始遗物、开始按钮、头像和背景均正常。
- [ ] 怀表位于能量图标附近，显示当前时刻；女爵获得辉星时只改变辉星本身，不改变时刻。
- [ ] 储君仍能正常获得、显示和消费辉星；女爵与储君联机时双方资源互不串用。
- [ ] 每回合开始时时刻为1；每打出一张牌只增加1；额外推进与设为3按文本结算。
- [ ] 时刻3/4/5/6/7卡牌仅在准确时刻金色高亮并触发，越过时刻后不继续触发。
- [ ] 旧怀表在时刻到达5时抽1张；从5以上设回3后再次到达5能够再次触发。
- [ ] 优雅身段洗入3张闪避并抽2；升级版洗入闪避+。
- [ ] 闪避只在回合进行中从抽牌堆抽到时变为0费，离开后重新生成或下次抽取不会永久继承减费。
- [ ] 重演在时刻5按本回合已造成的实际生命伤害动态显示和结算；力量、易伤与多段伤害不会重复计数。
- [ ] 洗回抽牌堆的卡牌顺序、选择界面和抽牌结算正常，不复制或丢失卡牌。
- [ ] 完美预演恢复回合开始时各牌堆归属和费用、移除本回合生成牌、将时刻设为3；不回滚生命、格挡、能力或已消耗能量。
- [ ] 双女爵及女爵+其他角色：时刻、反应、闪避和回溯快照不串玩家，所有指令保持同步。
- [ ] 图鉴、奖励、商店、升级、移除和衍生牌预览正常；基础、先古、衍生牌不混入常规奖励。
- [ ] Stable/Public Beta分别运行并完成保存、恢复和多人重连。

## 构建与风险说明

当前自动化只确认代码与本设备游戏程序集兼容。怀表控件取用了原版辉星计数器的显示外壳，但数据源完全独立；仍需实机确认不同分辨率、多个额外资源同时存在和跨角色卡牌场景下的布局。
