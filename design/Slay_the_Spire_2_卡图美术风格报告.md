# 2. 整体美术定位

## 核心关键词

-   奇幻冒险
-   黑暗童话
-   手绘感数字插画
-   强轮廓设计
-   戏剧化光影
-   夸张但易读的角色动作
-   神秘、荒诞、危险

《Slay the Spire
2》的视觉并非传统写实史诗幻想，而是强调"卡牌插画中的故事瞬间"。

核心原则：

> 一张卡图应该像一本奇幻图鉴中的一页，让玩家一眼知道"发生了什么"。

# 3. 画面语言分析

## 3.1 构图

推荐：

-   单一主体占据画面中心或黄金分割位置。
-   动作方向明确。
-   使用斜线构图制造力量感。
-   前景、中景、背景形成层次。

避免：

-   角色站立摆拍。
-   主体过小。
-   环境大于角色。

------------------------------------------------------------------------

## 3.2 轮廓

卡牌会被缩小显示，因此：

必须：

-   大形明确。
-   武器、防具、特殊能力拥有独特轮廓。
-   避免细碎装饰成为主要信息。

优秀设计：

"远处看是一把巨大长戟" "缩小后仍能看出是一个持盾骑士"

------------------------------------------------------------------------

## 3.3 色彩

整体倾向：

-   低饱和背景。
-   高对比主体。
-   一个核心强调色。

守护者建议：

金色： - 荣耀 - 防御 - 圣光

深蓝： - 城塞 - 冷静 - 风暴

赤红： - 战斗 - 反击 - 狂怒

青绿色： - 魔法领域 - 能量屏障

------------------------------------------------------------------------

# 4. 卡牌类型视觉规则

## 攻击牌

目标： 表现瞬间爆发。

关键词：

-   冲刺
-   武器轨迹
-   撞击
-   飞散碎片
-   命中瞬间

构图：

攻击方向占据画面主要空间。

禁止：

静止持武器。

------------------------------------------------------------------------

## 技能牌

目标： 表现策略、防御、准备。

关键词：

-   架盾
-   部署
-   机关
-   阵型
-   防御结构

构图：

强调角色与装备关系。

------------------------------------------------------------------------

## 能力牌

目标： 表现持续存在的力量。

关键词：

-   光环
-   领域
-   城堡幻象
-   风暴
-   神圣符文

构图：

角色不是唯一主体，环境力量成为主体。

------------------------------------------------------------------------

# 5. 稀有度表现

普通：

-   单主体。
-   简洁背景。
-   一个视觉事件。

罕见：

-   增加环境。
-   增加特殊效果。
-   增加叙事。

稀有：

-   史诗规模。
-   强烈光影。
-   世界级事件感。

------------------------------------------------------------------------

# 6. 守护者主题视觉库

核心元素：

## 重甲

表现： - 厚重 - 历史感 - 防御力量

不要： 所有牌都使用同一种铠甲。

------------------------------------------------------------------------

## 巨盾

适合：

-   防御
-   格挡
-   保护

变化：

-   城墙盾
-   能量盾
-   破碎盾
-   旋转盾阵

------------------------------------------------------------------------

## 长戟

适合：

-   冲锋
-   控制
-   反击

变化：

-   横扫
-   投掷
-   斩击
-   插地召唤领域

------------------------------------------------------------------------

## 城塞

适合能力牌：

-   防御领域
-   阵地
-   守护力量

------------------------------------------------------------------------

## 风暴

适合：

-   高稀有技能
-   终极能力

避免：

每张都画龙卷风。

变化：

-   雷云
-   风刃
-   暴风雪
-   电磁领域

# 8. 守护者Mod统一风格规范

所有卡图：

尺寸： 1000×760 PNG

禁止：

-   卡名
-   UI
-   数值
-   边框
-   水印

必须：

-   单一核心视觉记忆点
-   清晰主体轮廓
-   强动作表达
-   与其他卡明显区别
