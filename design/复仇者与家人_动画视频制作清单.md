# 复仇者与家人：动画视频制作清单

日期：2026-10-17。协作分支：`animate-0.1`。制作范围：复仇者本人及海伦、弗雷德利克、塞巴斯蒂安的基础动作。

**共21个合格视频：复仇者本人9个，三位家人各4个。每个编号对应一个独立动作视频。**生成次数按验收情况记录。领取任务时填写负责人和状态，交付时附上素材目录或可访问的交付链接。

## 1. 协作与制作规则

1. 开始前完整阅读 [角色战斗动画制作与 Mod 适配工作流](角色战斗动画制作与Mod适配工作流.md)，以及下文目标角色的视觉规范。
2. 先认领，再制作。多人同时处理时，每人使用自己的任务编号目录；调整共用参考图和首尾基准姿态时同步更新引用版本。
3. 每个角色先确认一份共用战斗基准姿态，随后制作该角色的其他战斗动作；商店、篝火按各自正式姿态单独建立基准。并行任务可以先准备提示词和构图方案。
4. 视频只表现任务指定的主体动作，灵魂波、雷电、刀光、治疗光效、召唤与消散由游戏侧统一配合。
5. 以预计游戏节奏审阅起手、释放和收招，再进入正式接入阶段。

状态建议：`待认领 → 已认领 → 参考确认 → 视频生成 → 视频待审 → 视频通过 → 透明序列 → 引擎验证 → 实战验证`。交接时明确当前状态。

## 7. 视频生成与交付

表中时长是**剪辑后完整动作的建议时长**。平台输出如为5秒或更长，可作为源视频，再按动作阶段剪辑与重采样。实际生成参数和原始视频时长随交付记录。

每项建议目录：`design/动画预览/revenant/<编号>_<动作名>/<版本>/`，包含：

- `reference.png`：本任务使用的批准参考图，另记源路径与SHA256。
- `prompt.txt`：完整提示词、模型／平台、分辨率、时长和可用生成参数。
- `source.mp4`：原始视频；多次候选按版本保存，标明最终采用者。
- `preview.gif`或预览播放器：供协作者快速审阅。
- `handoff.md`：负责人、任务编号、状态、首尾姿态、循环区间、释放／峰值的源时间与帧号、待办项。
- 透明处理阶段追加RGBA母版帧、透明边缘审阅图、颜色／锚点参数和适配记录。

生成要求：固定单镜头，主体及装备完整入画，稳定比例与锚点，清晰二维平涂、硬边阴影；使用与主体区分良好的均匀纯色背景，保持配色与光照稳定。一个视频只表现该编号的一个动作。交付采用文件夹，源视频与大帧集的共享位置按仓库素材策略登记。

## 8. 时间适配与接入验收

- 本人当前默认Attack等待0.15秒、Cast等待0.25秒。生成前确认本任务实际命令及释放目标；完整动作时长与命令等待分别记录。
- 家人的行动在 `src/Core/Models/Revenant/RevenantSummonManager.cs`，需逐分支核对动作启动、伤害与额外效果时点。FR03单独登记两次释放与两次命中。
- 动画交接同时提供原始素材节奏和预计游戏节奏，检查起手压缩、收招、正常／快速／瞬时模式、连续重播、受击打断和死亡。
- 接入时逐项记录“任务编号 → 卡牌／行动入口 → 实际触发 → 播放序列”，能力牌、技能牌和家人指令分别核对。
- 素材通过后依次完成透明序列、独立引擎、导出PCK、正式DLL与实战验收，并更新任务状态。

## 9. 配套效果与后续扩展

家人召唤入场3个、死亡／离场3个，共6个事件入口，采用游戏侧凝聚与消散效果模板适配各角色轮廓。它们作为配套效果任务登记，21个视频清单专注主体动作。

低血量待机及起手／收招、战斗放松、角色选择动态、呼唤／共鸣分别专用动作、防御／复活和篝火交互作为后续任务评估。复活敌人形成的死灵沿用原怪物美术与动作，并检查朝向、状态和事件接入。

完整基础版按21项执行。若采用18项首版，每位家人的A／B共用其A项攻击，HE03、FR03、SE03标记为后续独立制作项；协作前统一确认采用的范围。
