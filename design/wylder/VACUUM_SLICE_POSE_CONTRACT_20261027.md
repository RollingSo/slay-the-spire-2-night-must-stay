# 真空斩构图合同

使用本轮用户参考（本地已保存 skills_20261022/wylder_vacuum_slice_reference.png），不能画成原地持剑正面摆拍或狮子斩落地。

- 背左侧镜头，人物压低在左下部，头朝右下，背部弓起，胸甲正面不可见。
- 双肩低、肘内收，双手在左下低位同握直大剑；握柄向左后、刃身直线斜向右前上方，叉形柄头与护手/刃轴共线。风刃是分离的能量轨迹，不能把钢剑画成弯刀。
- 低骨盆、前膝高屈、前脚接地，后腿向后，重心压低；不是双脚离地后翻。可在大腿/后腿处取景裁切，但主要关节与握柄清楚。
- 右侧巨大竖向灰白月牙风刃占画面约三分之二，外缘锐利，内部2–3条宽风带，开口朝左；从低位向右前方发出，不画从头顶落下的竖直白柱。
- 身份：银色闭合羽翼盔、蓝后颈、黑围巾、银鳞、深蓝白流水纹衣裙、棕色手套绑腿；不复制参考裸人。
- 冷灰白风刃对深灰青平静背景，一条低对比地面线，不加火焰、碎石爆炸、密集粒子或封闭青色光圈。

六项指纹：下左小比例压低背影 / 背侧镜头 / 钢剑斜向右前、月牙风刃直立向前 / 冷灰白与深灰青 / 大块平静负空间 / 巨大开放月牙及宽风带。区别于狮子斩近景正侧落地、暖赭背景、窄纵落斩与地面接触线；也不同于上砍直立竖剑、猎犬空翻与圆盾背影上举。
