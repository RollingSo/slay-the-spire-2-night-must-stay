# 狮子斩动作合同

参考：`skills_20261022/wylder_lions_claw_reference.png`。不是猎犬剑技的空中后翻，也不是直立举剑。

- 前侧视角，前翻下砸后的压低落地瞬间，头盔在屏幕右侧朝右下，肩背拱起、胸腹收拢，躯干向右前倾接近水平。
- 右肩在较近侧、右肘下沉，右腕和右手靠近低位握柄；左肩在远侧、左肘内收，左手接同一柄。两条肩—肘—腕链都指向身体前下方，不生第三臂或第二剑柄。
- 骨盆在左，前腿深屈并承重，前脚贴地；后腿向左后伸展，不能将落地动作改为双脚悬空翻身。
- 默认追踪者直大剑，剑身沿低位向屏幕右延伸，剑柄、护手、刃根和剑尖在一条刚性轴上；叉形柄头在握柄后端。不沿用猎犬剑技曲刃例外。
- 银色闭合羽翼盔、黑围巾、深蓝白流水纹裙、分组银鳞、棕色手套绑腿；不照抄参考尖角盔甲。披风向上后方翻起，只支持落地惯性，不遮住握柄与两肘。
- 一条从上方下落到右下的宽灰白纵向斩迹表达前翻重砸，不能用绕身封闭圆环。背景暗赭红/炭灰平静大块，地面仅一块低对比平面，少量短接触线，不加火焰、碎石爆炸。

六项指纹：低位近景落地 / 向右前倾头在右 / 低位直刃横轴加落下竖斩迹 / 银蓝主体与暗赭炭背景 / 平静大负形与下部地面 / 宽纵向灰白落斩。区别于猎犬剑技灰绿背景的空中蜷身曲刃和开放C轨迹、上砍的直立伸展、回旋斩的扭腰横扫。
