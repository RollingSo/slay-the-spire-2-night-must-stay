# 追踪者首批实现（测试草案）

分支：`codex/wylder-development-20261018`；起点：main `60f3ccd`。不推送、不合并 main，也不替换现有本地游戏 Mod。

## 本批内容

- 角色入口、图鉴筛选、进度记录、历史头像、多人手势及主题接入。
- 初始牌组：4打击、4防御、钩爪移动、冲刺攻击；初始遗物单边耳环。
- 三张普通掉落牌：滑行飞跃、箭步：上砍、箭步：回旋斩。
- 未指定的角色基础参数暂用生命80、金币99；打击采用原生6→9伤害，防御5→8格挡，均耗能1。
- 单边耳环战斗开始进入追击。未新增专属药水或其他遗物。

## 机制边界

- 追击不会在回合结束退出。下一张攻击牌攻击伤害乘1.5，下一张技能牌额外真实抽1张；其他类型牌也会消耗追击。
- 出牌全过程保留旧追击，结算后消耗。钩爪移动在无追击时新进入的状态不会被这张牌立即消耗；旧追击下使用钩爪移动仍抽1张并保留重新进入的追击。
- 回旋斩在追击时使用原生群攻及AllEnemies目标，不逐敌人模拟单体攻击。追击条件满足时卡牌金色高亮。
- 上砍使用原生TemporaryStrengthPower的临时敌方力量降低/恢复流程，与已有角色同类效果保持一致。
- 破势按用户确认：扣除格挡后的实际攻击伤害，同一次出牌对同一敌人多段累计，群攻目标分开累计；任一敌人达标，每次出牌只触发一次。排除被动伤害、其他牌伤害与非结算阶段事件。使用每张可变卡独立弱引用状态，避免克隆共享计数。
- 本批用户指定的卡牌均没有破势奖励；框架已实装，并通过独立测试牌验证，没有向掉落池擅自加入示例牌。
- 两种机制均提供金色名称和独立带图标解释框。
