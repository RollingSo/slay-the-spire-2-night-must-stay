# 小圆盾格挡构图合同

用户参考与本地 `03_战技_Skills/085 - Buckler Parry.png` 视觉一致。使用背面举盾的瞬间，不改为正面举盾或持剑攻击。

- 背面镜头，头朝离开观众的方向，胸甲正面不可见。躯干稍向右扭，但背部仍是主要可见面。
- 解剖学左肩在屏幕左侧，左上臂、肘、腕向左上伸展，小圆盾抬到左上方，手在盾后握持；盾不能悬空。
- 解剖学右肩在屏幕右，右臂斜向右下，右手空拳；不添加大剑、攻击目标或第三臂。
- 骨盆基本直立、双腿承重微分，镜头可裁至大腿，不改成深蹲或翻滚。
- 盾是追踪者的小型海军蓝圆盾、银边与中心圆钉，面上三条弯曲银色纹饰；不是巨塔盾。
- 闭合银色羽翼盔的后侧、蓝色后颈、黑围巾、深蓝白流水纹衣裙、分组银鳞与棕色手套。背面不画前胸V甲或正面腰扣。
- 一条从左上向右下的灰白开放弧形挥盾余迹，背景为低饱和浅石蓝的两块宽静面，保留平静负空间。无爆炸、碎片、火焰或蓝色封闭光圈。

辨识指纹：背面上半身举小盾 / 镜头在人物背后 / 左上盾与右下空拳的对角线 / 深蓝银主体、浅石蓝背景 / 两块低对比大形 / 灰白斜向开放挥盾痕。与直立正面上砍、落地狮子斩、空翻猎犬、手部附火至少三项不同。
