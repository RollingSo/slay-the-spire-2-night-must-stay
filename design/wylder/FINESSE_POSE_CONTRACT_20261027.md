# 猎犬剑技重绘合同

来源：用户所附猎犬剑技动作图（已保存于 skills_20261022/wylder_bloodhounds_finesse_reference.png）。本牌武器是用户明确指定的异形武器例外，不使用追踪者默认直大剑，也不要求默认叉形柄头。

- 镜头：前侧面，人物正在空中后翻，躯干接近横斜，不站地、不落地蹲姿。
- 头/胸背：头盔位于左侧偏下并内收；胸腹向弯曲身体内侧，髋部高于肩部，不能以直立躯干代替翻身。
- 双肩与臂链：双肩位于躯干左侧；双肘内收，双手在身体下方的中右部共同控制同一柄武器。两条臂链可区分，不额外生成拳头或另一个剑柄。
- 骨盆/腿：骨盆抬到上方，两膝回收弯折，双脚离地；没有支撑脚。衣裙随旋转向后展开，不遮满手和武器根部。
- 武器：换成参考的灰白弯曲长刃，弧形刀身和末端轮廓沿身体右下方展开；握柄、护手与刃根连续。弯曲是参考中的实体形状，与错误弯折的默认直剑不同。
- 身份：银色闭合羽翼盔、黑围巾、深蓝白流水纹衣裙、分组银鳞和棕色绑带；不照抄参考角色的尖角盔甲。
- 动作阶段：上挑后退出接触区的后空翻；一条开放的宽灰白斩迹表达后翻，不能画成封闭青色光圈。

六项辨识指纹：近全身空中蜷转 / 前侧斜视头在左 / 横斜躯干与右下曲刃 / 银蓝主体、低饱和灰绿背景 / 大面积平静色域 / 开放灰白C形斩迹带少量暗红层。与上砍直立竖轴、回旋斩贴地扭腰、火焰系列全身挥斩/手部特写区别。
