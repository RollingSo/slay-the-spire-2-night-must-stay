# 追击能力图标与能量状态 UI

使用内置 imagegen，原始素材和旧图备份位于 `design/能力图标预览/追击_20261114`。

- 正式能力图标：`images/powers/wylder_pursuit_power.png`，256×256 RGBA；四角 Alpha 均为 0。
- 大图同步副本：`powers/wylder_pursuit_power.png`；沿用同名 AtlasTexture 映射，并显式覆盖追击能力大小图标路径。
- 用户否决第一版外围装饰；原外围钩爪已从正式资源删除，备份为 `rejected_external_grapple.png`。
- 第二版缺少白色流水纹路，用户要求保留原图身份；第二版不作为最终设计。
- 第三版基于原始 `wylder_orb_layer_1.png` 编辑，保留白色流水与深蓝底，仅加入内侧火焰星点、修改三爪边框。正式路径沿用 `wylder_assets/energy_counter/pursuit_orb.png`。
- 运行时：`src/Core/Nodes/Vfx/WylderPursuitEnergyVisual.cs`，由追踪者能量计创建补丁挂载。
- 仅读取所属玩家的追击能力；支持进入、消耗退出、恢复和重建。直接切换原有 Layer1 纹理，追击时隐藏普通状态的剩余图层；退出时还原纹理与可见性。数字沿用原标签。
- 无额外装饰节点、外部火焰、粒子、多边形或 Tween。只有状态变化时才切换纹理。
