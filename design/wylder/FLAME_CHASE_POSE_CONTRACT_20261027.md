# 燃火追斩构图合同

参照用户截图中追踪者低位侧身横扫、火焰从左下沿宽斩击弧向右上推开的瞬间，忽略界面和截图场景。旧截图剪贴板已失效，图像工具本轮使用角色身份与风格参考，动作由当前可见截图逐项转述；不声称将过期截图作为工具文件输入。

- 近侧后三分之四镜头，人物位于画面下部中左，躯干低俯，头盔朝向斩击前方；前腿弯曲、后腿支撑，身躯扭转而非站立施法。
- 右肩与双手、肘腕共同控制唯一大剑低位横扫；双手在同一握柄，两臂无断裂/第三手。单柄、叉形柄头、护手、直刃和剑尖共轴，钢剑不可弯，烈焰弧是独立轨迹。
- 宽火焰带从左下横穿画面，向右上方卷出，画成橙红与亮黄硬边色块。人物和剑柄在250×190仍可分辨，不让火焰完全遮住。
- 羽翼银盔、黑围巾、深蓝白流水纹、银鳞、棕护手靴。背景简化为深暖褐大色面，无草、树、城堡、游戏UI和字。
- 指纹：低身人物 / 侧后低角 / 接近水平的低剑与前向宽火带 / 深暖褐与橙黄 / 平静背景 / 单条横斩火弧。区别已批准炎击的直立上扬燃剑和深紫底，也区别附火的手与剑身局部特写。
