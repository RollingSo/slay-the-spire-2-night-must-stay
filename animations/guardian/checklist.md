## 制作顺序

1. **GD01 战斗待机 + GD02 长戟重击 + GD03 普通格挡**：先验证体型、盾牌、长戟轴线和羽翼剪影。
2. **GD04 受击 + GD05 死亡**：补齐战斗闭环。
3. **GD06 Steel Guard + GD07 防御反击 + GD08 翼风/施法**：补守护者机制动作。
4. **GD09 商店待机 + GD10 篝火待机**：补场景动作。

## 动作约束

- 守护者核心是“以重量换取控制”：起动慢、重心转移明确，不要做成轻型剑士。
- 普通格挡是身体移动到盾后，不是原地举盾摆拍。
- Steel Guard 分四拍：普通格挡 → 短垫步 → 盾面送正 → 压低扎根；不是盾击地面、单膝跪地或召唤盾墙。
- 防御反击不是盾击：盾只负责格挡和制造窗口，伤害动作是盾后短冲接长戟重击。
- 长戟头、套筒、杆身必须同轴；盾牌不能遮挡全部动作。
- 羽翼用于平衡、制动和风压，不是轻盈飞行；待机时低幅张合。

## GD01 待机提示词（图生视频）

参考首帧：`preview/guardian_idle_reference_green.png`（纯绿背景，1536×2048）。

```text
【图生视频｜首帧参考】严格以我提供的绿幕首帧图中的角色为准，保持图中的体型、装备结构、盾牌与长戟位置、羽翼剪影；不要改服装、不要换武器、不要增加部件。

【场景】纯绿色背景 #00FF00，全身，固定机位，正面略侧 3/4，角色完整入画，脚底不裁切；无地面、无影子、无文字、无水印、无特效、无景深、无镜头运动。

【动作】5 秒待机循环：0.0–0.3 秒保持首帧；随后以呼吸为主，胸口/胸腔缓慢起伏，肩甲与上臂随呼吸轻微联动；羽翼全程保持收拢，只允许翼尖和翼缘做很小幅度的跟随晃动，不要张开、不要抬翼、不要展开、不要扇动。盾臂与长戟只做毫米级跟随，不抬盾、不挥戟、不走步；4.5 秒回到首帧姿态并保持到 5.0 秒。动作幅度克制，重心稳定，体现“以重量换取控制”，不要轻飘。

【节奏】24fps，完整 5 秒；首帧与末帧尽量一致，便于循环；不要中途加速、停顿或切镜。

【负向】不要：换装、换武器、盾牌变形、长戟弯曲/多刃、额外肢体、翅膀穿模、张开翅膀、展开羽翼、抬翼、扇翅、翅膀大幅张合、角色漂移、走步、攻击、举盾、施法、特效、粒子、影子、地面、文字、水印、相机推拉摇移、景深、比例变化、裁切脚部。
```

生成视频后再从视频抽帧做 `.res`；不要把这张静图或 GIF 当作动画源。

## GD01 当前结果

- 采用 2 秒往返循环：源视频前半 f0–f24 正向，再 f23–f1 反向；不是直接裁段循环。
- 48 帧 / 24FPS / 2.0417 秒；转折帧时长 2 帧单位。
- 画布 414×631，锚点 202.612,624.164；纹理可见高 616（实际 618），最终 308.331。
- 独立复载通过；脚底 625 稳定，25 个唯一姿态；资源约 20.7MB（原 1353 版 92MB）。
- 正式资源：`main/combat_idle.res`；预览：`preview/guardian_idle_loop_2s.gif`。

## 尺寸结论

- 游戏内最终可见高度：**308.331px**。
- 采用 2x 最终尺寸：纹理可见高 **616**（实际复载 618），画布 **414×631**。
- 接入总缩放：`308.331 / 618 ≈ 0.4989`；如果挂在 `Visuals` 的 `0.6703` 下，局部缩放约 `0.744`。
- 当前 `guardian_combat_visuals.tscn` 的 `Visuals.scale` 是 **0.8235**（原型值），不是最终 308.331 的校准值；正式接入时必须改成目标缩放，不能直接沿用。
