# 雷电枪与雷击贴图

使用内置 image_gen，参考 lightning_spear.png 与 lightning_strike.png 卡图的雷电形态，没有修改卡图。输出 gold_lightning.png 为左右两个方形单元的 2:1 灰度亮度遮罩，黑色在 shader 中转为零覆盖率；左侧斜向雷电枪，右侧三道高低错落的雷击及地面电弧。

Visual style matches hand drawn graphic cel-shaded fantasy card-game VFX, medium refinement, broad readable angular shapes, controlled gray shadow energy, no thin-line web or dense sparks, no photographic lightning, no cinematic bloom.
