# 0.3.10 — 悬停预览修复与界面美术优化

发布日期：2026-10-06（Asia/Shanghai）。拉取远端 main 的4个新提交，发布基线 `bdfe6af`。

## 更新日志

- 修复内部能力缺少本地化标题时，部分卡牌悬停说明和预览无法显示的问题。
- 优化四角色共49个遗物／药水图标，加入49张独立轮廓贴图及13个药水轮廓映射，改善轮廓显示。
- 优化守护者、铁之眼、复仇者和女爵的角色选择背景笔触。
- 同步10个药水图集的裁切区域至256×256，并加入基础图标映射防回归检查。

## 验证

- 正式版与 Public Beta 编译、Duchess OnPlay JIT、固守自动格挡保留补丁和560个模型 ID 冲突检查通过。

- 本地49个图标、49张轮廓、13个基础药水映射和13个轮廓映射检查通过；隔离PCK加载124项资源全部通过。
